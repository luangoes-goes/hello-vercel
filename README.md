# hello-vercel

Página estática básica ("Hello World") feita em **Next.js** (Node.js), pronta para deploy na **Vercel**.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000

## Build de produção

```bash
npm run build
npm start
```

## Deploy na Vercel

1. Suba este projeto para um repositório no GitHub.
2. Acesse https://vercel.com/new e importe o repositório.
3. A Vercel detecta o Next.js automaticamente — é só clicar em **Deploy**.

## Estrutura

- `app/page.js` — a página principal (edite aqui)
- `app/layout.js` — layout raiz e metadados
- `app/globals.css` — estilos
